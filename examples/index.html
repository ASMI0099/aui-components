Fields

aui-select

Products from the server page by page with server search, a field that depends on another, saved values looked up by id, large static lists.

aui-tree-select

Categories loaded level by level, server search, a node with 2,000 children in pages, saved values revealed down their path, a whole tree of up to 100,000 nodes.

aui-input

The form, basic and cell styles next to the selects: counts, numbers with limits, passwords, search fields, checks in a page form.

aui-date-picker

Days, date-times, times, months, quarters, years, weeks and several dates, single or as a range: typing, keyboard, limits, shortcuts, timestamps.

aui-checkbox

States and sizes, a page form, a table with select-all, aui-checkbox-group with select-all, min and max, layouts.

aui-pagination

A list loaded page by page with loading, sizes, simple, a narrow place, the page model.

Actions and overlays

aui-button

Variants, intents, sizes and shapes, icons, a loading state that waits for a promise (no double submit), disabled with a tooltip.

aui-popover

A card next to its trigger: an edit icon in table rows, the page's own triggers, is-open and api, the placements, fields inside.

aui-modal and messages

Dialogs in a template and from code, confirmations that wait for a promise, notices that go away by themselves.

Use cases

A search form

Store, department, categories and products that depend on each other, with saved values and a static list of every product.

Test suites

Every browser suite is a page that runs its checks when opened and shows the report at the bottom (keep the window in front while it runs). npm test runs all of them in a headless browser.
